# Elenoyze Reference Hub

A personal project exploring a Pinterest → GitHub → ChatGPT creative-reference workflow.

## Project status

**Planning / development.** Pinterest API access and AI integration have not been implemented. The repository currently contains a public privacy-policy page for a Pinterest developer application request.

## Intended workflow

- Authenticate a Pinterest account with appropriate permissions.
- Retrieve authorized board and Pin information in accordance with Pinterest API rules.
- Help organize motion design references and, where permitted, support user-requested creative analysis.
- Never commit API tokens or secrets to the public repository.
- Do not create a public archive of Pinterest content.

## Publish with GitHub Pages

In the repository, open **Settings → Pages → Build and deployment → Deploy from a branch**, choose **main**, **/(root)** and click **Save**.

Once the deployment is complete, verify the public page:
